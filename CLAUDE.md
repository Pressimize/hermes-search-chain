# Notes for Claude Code

Second opinion from free models: the private tool repository `Pressimize/second-opinion` (clone it next to this repository with `git clone https://github.com/Pressimize/second-opinion ../second-opinion` and follow its README).

- In a cloud session, get a second opinion before pushing a change to code (not for typo fixes in the docs). If the tool repository cannot be cloned, say so in the PR text and continue without it.
- In a local session, do not get one on your own; review with Claude helpers instead. Get one only when the maintainer explicitly asks for it.

Earlier reviews and the points they settled are in `docs/reviews/`. Read them before raising a point again.
